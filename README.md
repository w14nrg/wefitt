# We Fitt — wefitt.uk

Website for We Fitt, a trading name of En-Suites & Bathrooms Ltd, 287 Munster Road, Fulham SW6 6BW.

- `site/` — source: page content (`pages_content.py`), build script (`build.py`), CSS and JS
- `docs/` — the built site that GitHub Pages serves (do not edit by hand; run `python3 site/build.py`)

The site is set to **noindex** until launch (`NOINDEX = True` in `site/build.py`).
